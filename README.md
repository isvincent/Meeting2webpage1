# 📅 楊梅高中 114 學年度第 1 學期 擴大行政會報活動總覽

將桃園市立楊梅高級中等學校 **114 年 8 月至 12 月共 5 次擴大行政會報會議紀錄**中提到的活動整理成一頁網頁，所有活動依時間先後排列。

- 共 **168 項活動**，時間從 2025/7（民國 114 年 7 月）到 2026/2（民國 115 年 2 月）
- 依月份分段的時間軸，每筆活動標示日期、星期、處室、類別、起訖日期，以及出自哪幾份會議紀錄
- 有辦理結果的另外標示（例如 🏅 全國工科技藝競賽金手獎第四名、管樂社學生音樂比賽優等）
- 可用關鍵字搜尋，也能依 **類別／處室／會議紀錄** 篩選
- 上方有月份快速跳轉列，並支援深淺色切換與手機版面

## 📁 檔案架構

```
ymhs-meeting-activities/
├── index.html            ← 首頁（頁面結構）
├── README.md             ← 本說明文件

    ├── css/

```

這是純靜態網站，不需要安裝套件或建置，直接用瀏覽器開啟 `index.html` 就能看。

## 🚀 上傳到 GitHub 並發布

1. 在 GitHub 建立新的儲存庫，例如 `ymhs-meeting-activities`（設為 Public）。
2. 把本資料夾內的所有檔案上傳，包含 `.nojekyll` 和 `assets/` 資料夾：
   - **網頁上傳**：在儲存庫頁面點 **Add file → Upload files**，把整個資料夾的內容拖進去，再按 **Commit changes**。
   - **使用 Git 指令**：

     ```bash
     git init
     git add .
     git commit -m "初版：114學年上學期擴大行政會報活動總覽"
     git branch -M main
     git remote add origin https://github.com/<你的帳號>/ymhs-meeting-activities.git
     git push -u origin main
     ```
3. 進入儲存庫的 **Settings → Pages**，在 **Source** 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`，按 **Save**。
4. 等 1～2 分鐘，頁面上方會出現網站網址。

> 💡 Windows 檔案總管預設不顯示以「.」開頭的檔案。如果拖曳上傳時漏掉 `.nojekyll`，網站通常還是能正常運作。

## ✏️ 新增或修改活動

所有活動資料都在 `assets/js/data.js` 的陣列 `D` 裡，每一列代表一項活動：

```js
// [起日, 迄日, 名稱, 處室, 類別, 說明, 出現於哪幾次會議, 成果(可省略), 註記(可省略)]
['12/9','12/12','全國工科技藝競賽','實習處','競賽成果','岡山農工；12/9 報到…',[8,9,10,11,12],'電腦修護職種榮獲金手獎第四名…'],
```

| 欄位 | 說明 |
|---|---|
| 起日／迄日 | 格式為 `月/日`。月份 **7–12 視為 2025 年（民國 114）**，**1–6 視為 2026 年（民國 115）**。迄日沒有就填 `''`；起日填 `''` 的活動會放在「未標明日期的活動」區 |
| 處室 | 例如 教務處、學務處、總務處、實習處、輔導室、圖書館、人事室、秘書、校長室；處室篩選選單會自動產生 |
| 類別 | 必須是 `CATS` 裡定義的類別之一：學生活動、研習講座、考試測驗、競賽成果、國際交流、升學生涯、展覽閱讀、會議、健康環境 |
| 出現於哪幾次會議 | 會議月份陣列，例如 `[10,11]`，對應 `MEET` 的設定 |
| 成果 | 填了才會顯示。類別是「競賽成果」時顯示 🏅，其他類別顯示 📌 |
| 註記 | 例如「原訂 11/13」，會以小字顯示 |

活動不必依日期排序，網頁會自動排序。

**新增一次會議紀錄**（例如 115 年 1 月）時：
1. 在 `MEET` 加一筆，例如 `1:'1月會報（115/1/xx）'`
2. 在 `D` 加入新活動，並在既有活動的會議陣列補上 `1`

如果活動時間超出 2025/7–2026/2，請一併修改 `app.js` 中月份導覽列的起訖範圍（`new Date(2025,6,1)` 到 `new Date(2026,1,1)`）。

## 📚 資料來源與說明

- 資料來源：楊梅高中 114 年 8、9、10、11、12 月份第 1 次擴大行政會報會議紀錄。
- 8 月紀錄的文字直接從 PDF 擷取；9–12 月是掃描檔，經 Windows OCR 文字辨識後再人工核對整理。
- 同一活動在多次會議中出現時，已合併成一筆，以較新的紀錄為準，原先日期另以註記保留。
- 日期依會議紀錄所載，實際辦理情形請以學校公告為準。
- 原始會議紀錄 PDF 屬校內文件，**沒有放進本儲存庫**。
